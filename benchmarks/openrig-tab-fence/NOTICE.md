# Provenance and scope

Upstream: mvschwarz/openrig, Apache-2.0. Full source is fetched at the manifest revision; `fixed.patch` contains the two minimal proposed scanner changes against that source. Specifications and regression assertions were written independently by the TestLore investigator using the public CommonMark 0.31.2 specification (CC BY-SA 4.0, John MacFarlane) and existing public OpenRig behavior. This folder contains original assertions and paraphrases, no copied CommonMark test text. See primary links in specification.md.

Discovery is manual; these are new investigator tests, not untouched upstream tests or TestLore-discovered defects. Native Codex proposals and static review are recorded in `candidate.json`; module regressions pass but complete native qualification, maintainer submission/acceptance, faster selection and learning advantage remain unestablished. Candidate evaluation must preserve every original native case and identify unchanged opt-in skips/todos separately.

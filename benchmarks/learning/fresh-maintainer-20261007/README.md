# Four fresh maintainer contracts, two repetitions, both arms

This completed controller run used Codex CLI 0.155.1 with native ChatGPT subscription authentication and stripped API keys. It ran **48 role calls** at frozen TestLore revision `59004607b8b3584664d6bc16556120ce9b1b195b`. The provider model and dollar billing remain unknown. [Aggregate](aggregate.json) retains every trial, reference-run outcome, failure, timing and raw-receipt hash.

The [prospective dataset](../../public-generation/fresh-maintainer-contracts-v1/README.md) binds maintainer READMEs, original assertion bodies and genuine fixed/first-parent defects from vercel/ms, then/is-promise, sindresorhus/is-plain-obj and sindresorhus/is-stream. These contracts were unused in earlier local live assays. That does not establish secrecy or exclusion from model training. Declared framework/entrypoint adaptations preserve assertion bodies; these are not full original AVA/Mocha installations.

All four reference suites passed against fixed source and failed against their genuine historical parent, twice each. Both generated arms missed the milliseconds decimal defect in both repetitions. The memory arm's second milliseconds trial was independently rejected: its error assertions had no authoritative specification. Rejected outputs stay in the denominator and contribute zero detection. Fewer generated cases do not establish better quality.

The two arms had identical worker argv, 115-second per-call deadline, 65,536-byte response bound, three roles, no retries and two stability runs. Memory increases input size. Native completion events reported 934,168 input tokens, including 133,120 cached input tokens, and 19,846 output tokens across all 48 calls. These are locally audited worker counters, not an externally verified invoice or enforced token budget. Controller time through cleanup was 885.896 seconds; per-trial totals include setup, retrieval, generation, validation and defect execution, excluding shared reference preparation and final receipt writing.

**No learning gain is demonstrated.** Detection differences were zero for all four specification units; one pair was incomplete. Four specifications and two repetitions are also below the evaluator's six-specification, three-repetition inference threshold. Learning remains advisory and cannot authorize omissions or deployment.

The experiment found two implementation limits. Its frozen retrieval treated generic language names and source paths as contract overlap, returning unrelated clamp history. Its frozen Node reporter could assign incorrect readable parent/case names when suites overlap or declarations share a location. Assertions, occurrence-based IDs, statuses and counts are retained, but these names cannot support exact case-name claims. Later relevance and reporting fixes are separate work; they do not rewrite this result or establish a learning improvement.

# Fresh maintainer cohort

This prospectively frozen cohort has four specification units not used in the earlier live generation assay: ms, is-promise, is-plain-obj and is-stream. Source, maintainer README contracts, original test assertion bodies and licenses are bound to exact upstream Git blobs. Each defect is the exact historical first-parent source, not a generated mutation.

The original assertions pass the fixed source and fail the parent source twice under the declared Node adaptations. This checks usable labels; it does not establish generated-test effectiveness.

Transport replaces AVA/Mocha/expect.js entry points with Node test/assert equivalents. Stream transport additionally provides disposable tempy paths, redirects the relocated `test.js` read to this test file and closes opened streams after each case. Assertion bodies stay byte-identical. These adaptations do not qualify original dependency installations or historical Node versions.

The prospective paired protocol uses two repetitions, two balanced arms and three roles per successful trial: at most **48 native calls**, 115 seconds and 64 KiB per call, zero retries, and two independent stability executions for each baseline/defect. Agent inputs exclude reference assertions and parent bytes. The original distinct authored clamp history is retained unchanged. Retrieval may have no applicable lessons; that remains visible and invalidates a learning-gain inference. Input/output token usage is measured where native events expose it; billing and actual model identity remain unverified.

Four independent units and two repetitions are below the evaluator's inference threshold. Neither completion nor an observed difference authorizes learning promotion. A local commitment does not prove semantic independence, model-training isolation or external publication time. Results must be collected separately against an immutable source revision; this dataset is not itself a completed experiment.

Rebuild into a new directory with explicit network access:

```sh
node scripts/public-generation-dataset.js --fetch --output NEW_DIRECTORY --cohort fresh
```

Upstream license notices are archived beside each exact oracle revision. The original cohort and its retained results remain unchanged.

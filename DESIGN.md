# TestLore design

## Direction

A maintainer reads the evidence story beside a terminal and code review on a dim desktop, looking for confidence rather than spectacle. Use the user's approved Cognitum reference: ink surface, mint highlights, generous type and a legible circular observation loop. The page is a static product explanation, never a live status dashboard.

## Tokens

Use OKLCH tinted ink backgrounds (0.16 0.018 225), slightly lighter panels (0.20 0.025 225), warm near-white text (0.96 0.006 150), quiet secondary text (0.78 0.014 220), and mint (0.85 0.12 165). Amber marks challenges; color always accompanies text.

## Typography and layout

Use local Helvetica Neue / Arial for an offline terminal-adjacent technical voice. Large, tightly spaced headings, calm body copy capped at 65ch and small monospace stage labels. An asymmetric two-column evidence narrative stacks on narrow screens. Use rows and one large loop illustration; avoid an identical card grid.

## Behavior

The diagram shows a labeled example state. Users can inspect each stage, toggle an illustrative recorder-failure scenario and pause animation. Reduced motion disables loop motion. Include a skip link, visible keyboard focus and a static fallback. No fake live counters, gradient text, decorative blur or side-stripe callouts.

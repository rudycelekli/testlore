## October 9 source-repair and public-repository work

The source workflow now adds bounded source repair separately from test generation. Existing assertions, configuration and dependencies remain immutable; native Node assertion failures must repeat before a candidate can be promoted. Automatic PR publication now verifies GitHub metadata and the remote tested SHA. Opt-in default-branch agent automation requires a configured trusted runner; ordinary installation does not imply a running service. [Repair contract and adoption](autonomous-repair.md).

New public observations retain negative outcomes. REA’s completed three-seed matrix selects 234/261 files, but schema-object title drift blocks qualification and TestLore remains slower. The actual native skipped-registration experiment links three original skipped rows across two native arms; it is not omission authority and does not retroactively qualify those measurements. Claude-mem has four independently passing Bun scopes, a full-suite timeout and five existing browser failures; earlier diagnostic trials fell back to every route file and were slower. The new prerequisite gate prevents treating those diagnostics as qualified regressions. Contributed e2e’s six completed comparisons retain the Unicode fault but fall back to all 174 files; duplicate case titles block qualification, and observed complete TestLore processes remain slower than native selection. Supported AQE author attempts rejected upstream before TestLore received drafts, so no combination advantage is established.

These observations do not increase the qualified upstream benchmark denominator. Fresh source/archive CI and real-provider repair results are bound to their own revisions; deterministic worker tests do not establish model repair quality, learning improvement or superiority.

The actual native Codex source-repair campaign completed three delegated roles and fixed one historical whitespace defect against eight adapted, unchanged Node cases. The two baseline failures repeated; two candidate runs and the final branch run passed all eight cases. The caller stayed unchanged, and no PR was published (`--local`). The original Mocha discovery rejection and input-provenance correction remain recorded. [Exact scope and frozen receipts](../benchmarks/agent-source-repair/native-codex-20261009/README.md).

Feature source `88e96717b844c72a82d214bb1d81a702135249f9` passed all six core hosted jobs, including **871/871 complete-source tests with zero skips or failures** and native Bun/Chromium cases. Its sealed production-package check exercised installed autopilot with a deterministic delegated worker, rejected wrong-source and assertion-edit attempts, and verified the exact tested source commit. This archive is not a live provider-to-GitHub PR trial and does not qualify later source changes. [Exact-head CI](https://github.com/rudycelekli/testlore/actions/runs/37955658954). Native provider repair cost remains unknown; ongoing self-hosted automation and a subsequent npm release still need separate qualification.

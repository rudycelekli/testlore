# Engineering acceptance status

TestLore remains experimental. The following results distinguish implemented mechanisms from demonstrated benefits. A candidate inventory, successful installation or passing generated suite is not a qualified regression benchmark.

| Acceptance area | Observed evidence | Remaining acceptance work |
| --- | --- | --- |
| Complete-run performance | Fresh planning batches baseline Git reads and retains four independent startup/execution snapshots. Public ufo still loses to native selection; outliers remain published. The guarded worker syntax reuse has correctness checks, without a new complete-run speed claim. | Measure the new worker on matched full/native/legacy/unified runs, including reporting. Preserve fresh executable configuration and drift challenges. |
| Complete application profile | Original Vite React 4.7.0 full frozen installation and recursive build completed. Its unchanged plugin unit tests passed 2/2; the original serve browser suite passed 62 cases with two explicitly pending maintainer cases. | Build-browser baseline, independent source/style/workspace/server faults, full/subset challenges and reviewed omissions remain incomplete. No complete application routing qualification. |
| Genuine upstream benchmark | Combined public evidence is 11 unique changes across four repositories; only **one change in one repository** has qualified its original upstream-lock environment. That unctx run retained the fault twice, fell back fully and was slower than native selection. | Reach 30/5, then 100/10 with original installations and stable independent faults. New portable unctx/mlly campaigns do not add results until executed and reviewed. |
| Generation effectiveness | Four fresh maintained specification units, two repetitions and 48 actual native role calls: no-memory completed 8/8 trials and detected 6/8 historical fault exposures; memory completed 7/8 and detected 6/8. Existing maintainer assertions independently demonstrated the faults. | Broader untouched units, real bugs, stable completions and comparable costs. Preserve the independent review rejection and frozen assay limitations. |
| Learning contribution | The fresh paired assay established **no improvement**. Generic transport terms are now excluded from contract matching. A later native reporter replay preserved the 15 accepted generated outputs' original outcomes. | Evaluate the corrected retrieval on a new prospectively frozen cohort. Retrieval matches are not semantic applicability; learning remains advisory. |
| Agent adoption | One actual native Codex invocation completed seven ordered MCP calls, a bounded supplied historical source repair and fresh full verification against eight preserved maintainer assertions. | Claude authentication and successful execution; broader application repairs. The supplied repair instruction qualifies the workflow, not autonomous bug solving. |
| Distribution | PR #13's exact source and archive were independently checked from hosted artifacts: 589/589 source tests, zero skips/failures, three required native Chromium cases and qualified production installation. | Establish npm ownership and trusted publisher mapping, publish and verify registry bytes. A GitHub install is available; npm publication is not established. |

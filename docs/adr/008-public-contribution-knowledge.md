# Public contribution retrieval with independent repair authority

Status: Implementation candidate; exact-source checks and replay govern qualification
Date: 2026-10-11

## Decision

Keep a local, separately sealed public-authored contribution corpus. Collect read-only GitHub metadata with exhaustive date-partitioned pagination, explicit public visibility and bounded detailed sampling. Retain captured scope and incomplete results. Import only public external nonfork targets with exact identities and source hashes. Classify bounded identifiers into a fixed hypothesis taxonomy without copying patches or free-form instructions. Preserve merged/open/draft/closed observations separately; neither a merge nor a repeated title is a verified defect fix.

Provide explicit local import, reflection and contract-anchored lookup commands. Allow opt-in source-repair architects/authors to retrieve bounded advice, preserving a blind independent reviewer. Bind and freeze the ignored knowledge input throughout the isolated repair workflow. Project requirements, production scope, original assertions, native case preservation and repeated validation retain all acceptance authority. Missing/corrupt knowledge cannot upgrade a candidate; concurrent knowledge changes fail the round.

Use deterministic lexical retrieval first. RuVector and embeddings are optional future derived retrieval experiments, not necessary storage, training or correctness mechanisms. Do not upload private contribution histories or automatically share local records. Credentials never enter model prompts or captured diagnostics.

## Qualification

Challenge pagination truncation, ignored date filters, search drift, nonpublic records, ambiguous outcomes, malformed identities, symlinks, corrupt/rehashed claims, held-out repositories, unrelated contracts and complete JSON byte budgets. Exercise actual worker transport and the complete repair staging/verification path, including disabled and missing stores and concurrent mutations. Freeze independent retrieval cases with repository and absent-family holdouts; report relevance, abstention, total lookup latency and bytes without calling this a repair-quality improvement.

A subsequent matched-budget live repair experiment needs independently maintained untouched specifications and real defects, not copied upstream solutions. Count completion, unchanged native assertions, independent defect detection, stability, total time and cost. Retain rejected and timed-out trials. Promote learning only after repeated gains; a local knowledge feature or green CI is not that evidence.

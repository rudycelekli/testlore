# ADR-004: Measured planning and audited worker completion

Status: In progress. Date: September 30, 2026.

The last qualification campaign exposed planning overhead and incomplete generation. This milestone measures planning phases and improves repeated work within a fresh plan without reusing evidence across independent runs. Source, configuration, environment, runner and runtime changes must continue to invalidate selection. Unknown dependencies retain full fallback. Planning timings do not participate in evidence fingerprints.

Native Codex generation must provide a bounded, well-formed event stream, terminal success, schema-valid final payload and agreement with the response file. Tool attempts, malformed events, missing completion, late responses and executable drift invalidate the response. Event auditing detects reported activity; it does not establish an operating-system security boundary or verify the default model.

Learning experiments bind resolvable worker launchers and source scripts and retain identity drift as failed attempts. Operator identity remains a declaration. Existing frozen experiments are not rewritten or reused to demonstrate improvement.

A separate opt-in native exercise uses one new independent contract, three reference-demonstrated faults, repeated native outcomes and a fixed three-role budget without retries. It tests bounded completion and defect detection, and cannot establish a learning gain, general test quality, full MCP host qualification or npm publication.

Promotion requires focused negative checks, complete source tests including Chromium, hosted checks and the exact installed archive. Scoped measurements and unresolved account/host gates remain visible.

# Contributed-project campaign: tester-army/e2e

This campaign targets the merged [Unicode glob contribution, PR #927](https://github.com/tester-army/e2e/pull/927). It is a genuine upstream source regression with retained upstream tests. Rudy authored the contribution and its new Unicode assertions: it **does not establish independent test authorship** or independent benchmark maintenance.

The preregistered checkout is `0ddea76a7091ac8768e0ced2a9926b37e72e9497`; source reversion uses the two exact parent files from `b2a28d4813df9e0c0816cfffbdb51f4cc4e04faa`. Original configuration, tests, package declarations and lockfile remain intact. This restores the missing `u` regexp flag and old character escaping while retaining later tests; it is not the complete original historical environment.

The original environment is inspected at the pinned revision: [pnpm 12.3.4](https://github.com/tester-army/e2e/blob/0ddea76a7091ac8768e0ced2a9926b37e72e9497/package.json), [Node floor 22.22.3 and Vitest 5.0.1](https://github.com/tester-army/e2e/blob/0ddea76a7091ac8768e0ced2a9926b37e72e9497/packages/e2e/package.json), [original unit/integration configuration](https://github.com/tester-army/e2e/blob/0ddea76a7091ac8768e0ced2a9926b37e72e9497/packages/e2e/vitest.config.ts), and [build-first instructions](https://github.com/tester-army/e2e/blob/0ddea76a7091ac8768e0ced2a9926b37e72e9497/AGENTS.md). The lock SHA-256 is `8fc2fe6cf6b13b501483f30854e7fe56a957cfce04ac41c8ce2a7cadcd8f4896`.

The hosted job installs the original frozen monorepo lock, executes the original root build in its original package order, and runs **the complete original e2e unit project**. It excludes integration/browser/provider/mobile/application suites and makes no whole-project claim. Every originally tracked input other than the two reversion sources is hashed before installation and rechecked after execution. A quality configuration file is added only in the disposable clone.

For a comment-only control and the Unicode regression, three repetitions rotate independent full/native-related/TestLore execution order. Native related selection receives the actual changed paths. Timings cover complete test CLI processes, including startup, planning, execution, serialization, report retention and exit. Original builds are rerun after each source change and restoration so built-package consumers also see the change; this shared preparation is recorded separately and excluded from the per-arm test timings. OS caches are not reset; these are ordered repetitions rather than qualified cold/warm measurements. Local history and analysis state are removed before each repetition. TestLore is installed from a sealed source candidate, with archive binding retained; it is not the published npm version.

Qualification requires the exact original named baseline, real Unicode assertion failure, preserved passing/skipped/failing cases in every executed file, no TestLore omitted failure, explicit native missed failures, understood omissions and restored green baseline. Duplicate case names are rejected rather than assigned cross-run ordinal equivalence. File-load errors, interruption, unsupported reports, missing trials or changed protected inputs cannot qualify. Timing losses and conservative full fallbacks are retained. A completed comparison and a qualified result are separate outcomes.

Run `Contributed e2e public evidence` through GitHub Actions. The workflow has a 30-minute deadline; the campaign stops at 25 minutes, bounds each native process, checks a 2 GiB disk reserve, limits logs and inherits no provider credentials. Raw JSON, process logs, event timings, input bindings and the independent assessment are uploaded even after failure. No model budget is allocated; model cost is not measured. No result or speed advantage is claimed until a hosted run finishes and its original receipts are inspected.

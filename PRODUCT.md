# Product

## Register

brand

## Users

Developers, maintainers and coding agents working in JavaScript and TypeScript repositories. They need useful tests and understandable verification without repeating every expensive test for every small change. Repository adoption, agent access and independent evidence matter more than a marketing score.

## Product Purpose

TestLore is an open-source, complementary quality-engineering layer. It coordinates specialist tools, modular dependency reasoning, full-shadow verification, independent candidate review and local advisory learning. Success means catching defects, preserving existing contracts, explaining omissions and measuring the complete cost against native selectors. The evidence loop records native observations, challenges claims and retains reviewed outcomes.

## Brand Personality

Curious, rigorous, generous. Show ambitious engineering with candid evidence. The user selected TestLore and requested a promotional README, easy installation, agent access and the functionality AND visual direction of the supplied Cognitum evidence-loop reference.

## Anti-references

Unsupported best-in-class rankings, fabricated percentages, dashboards presenting old receipts as live health, and self-improvement described as established without measured gains. Avoid generic decorative statistic cards; let the verification story carry the page.

## Design Principles

1. Lead with the purpose, then show how the loop works.
2. Separate a healthy test result from the health of its evidence recorder.
3. Every claim has a visible scope and a path to its supporting evidence.
4. Native tools keep their authority; retained lessons stay advisory.
5. Make one-command adoption and agent entry points easy to find.

## Accessibility & Inclusion

Use semantic headings, keyboard-accessible controls, sufficient contrast and text alongside state colors. Respect reduced motion. Render the page without external fonts, tracking or a required network connection. These are implementation requirements, not an accessibility certification.
